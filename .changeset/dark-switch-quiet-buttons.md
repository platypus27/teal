Fix Switch and Button states that misread in dark mode and high contrast. An unchecked Switch no longer fills its track with the primary container color in dark mode, which made it look switched on; the off state now follows the Material 3 pattern with an outline track on a neutral surface container and a smaller outline-colored thumb, so off reads as off in light, dark, and forced-colors modes, where the switch thumb, checked track, and disabled buttons resolve to system colors with authority over the state utilities. The checked thumb now uses the on-primary token so it keeps at least 3:1 contrast with the primary track in both themes, the thumb sits at a 1px inset inside the track in both states and sizes and moves logically in RTL, and a subtle Material 3 state layer restores hover feedback on enabled switches. Button and IconButton disabled states no longer rely on opacity alone, which kept a dimmed primary looking active on dark surfaces; disabled buttons now use an explicit on-surface treatment (12% container, 38% content, no border or shadow) with a not-allowed cursor. Disabled buttons now also receive pointer events, so tooltips work and clicks no longer pass through to elements underneath; hover and press feedback stay suppressed on disabled buttons while links composed via asChild keep theirs.
