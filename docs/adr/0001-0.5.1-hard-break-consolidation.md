# ADR-0001: Ship 0.5.1 as a hard-break component consolidation

- Status: Accepted
- Date: 2026-08-14
- Release: `@kryv/teal` 0.5.0 → 0.5.1

## Context

Post-0.5.0 the library carried ~170 components with heavy duplication: four
date-picker variants, five dialog-family overlays, near-identical slider,
table, menu, and input pairs, and more. A consolidated 0.5.1 design spec
(`docs/archive/specs/2026-08-14-teal-0.5.1-fixes-and-consolidation-design.md`)
covers ~25 reported issues plus a full-library sweep. Consolidation requires
deleting old component names, which is a breaking API change.

Teal is pre-1.0 and consumed only by Kryv applications, so the blast radius of
a hard break is small and known.

## Decision

Ship 0.5.1 with a hard break: absorbed component names are deleted outright
with no deprecated alias re-exports, in a patch release, with explicit user
approval of the semver exception.

Key elements:

- 24 merge groups absorb duplicated components into canonical ones with mode
  props (e.g. DatePicker gains `mode: 'day'|'month'|'year'|'datetime'` and
  `selection: 'single'|'range'`; Dialog gains `placement` absorbing Drawer,
  BottomSheet, and FullscreenDialog). Components with genuinely distinct ARIA
  semantics or value formats are explicitly not merged.
- Naming stays flat (no `X.Item` dot-notation); one component per file, flat
  barrel exports.
- Internal dedup only where no API changes (shared date utils, one
  `useScrollSpy`, one MenuItem renderer, shared form-field scaffolding).
- The changelog carries a full old-component → new-usage migration table.
- Docs regroup keeps existing module slugs wherever possible so external
  bookmarks survive.

## Consequences

- Consumers migrate in one pass against the migration table instead of living
  through a deprecation cycle.
- The catalog shrinks to a defensible core (168 documented modules in 11
  groups) with one place per behavior.
- No aliased dead code is carried forward.
- The accepted risk: any consumer pinned to removed names breaks until
  migrated; mitigated by the small, known consumer set and the changelog
  table.
