# teal 0.5.1 — Docs App & Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the docs-app half of the 0.5.1 spec (spec Part 2: sidebar double-active, fixed-position demos escaping the preview box, placeholder external links, module-meta performance split, IA regroup onto the merged component set) and the release mechanics (spec Part 4: updated Playwright coverage + visual baselines, changeset with the full migration table, final verification gate).

**Architecture:** `apps/docs` (React Router + Vite) renders one page per component from `src/data/module-meta.js` (currently one 10,205-line eager module). This plan splits it into a light eager index (`src/data/module-index.js` — id/name/description/apiNames per module, consumed by sidebar, search, PrevNext, HomePage via `docs-module-registry.js`) plus one lazily-`import()`ed metadata file per module (`src/data/modules/{id}.js`, loaded by `catalog.jsx`'s `loadModuleRecord`). A Node-only barrel keeps the old `module-meta.js` export surface (`moduleGroups`, `modules`, `moduleGuidance`) for build scripts and the Playwright spec. Merged-away module ids are handled with a `moduleRedirects` map + `<Navigate>` in `ModulePage` (the simplest option the current declarative `<Routes>` setup supports — no router changes).

**Tech Stack:** React 19, React Router, Vite, Tailwind, Playwright, changesets

```js
#!/usr/bin/env node
// One-off codemod: splits src/data/module-meta.js into a light eager index
// (module-index.js) and one lazily loaded metadata file per module
// (modules/{id}.js), then rewrites module-meta.js as a Node-only barrel.
// module-meta.js attaches `guidance` onto each module object at import time,
// so the JSON payload below already includes it. Delete this script after use.
import { mkdirSync, writeFileSync } from 'node:fs'
import { resolve } from 'node:path'
import { moduleGroups } from '../src/data/module-meta.js'

const dataDir = resolve(import.meta.dirname, '../src/data')
mkdirSync(resolve(dataDir, 'modules'), { recursive: true })

const varName = (id) => `m_${id.replaceAll('-', '_')}`

for (const group of moduleGroups) {
  for (const module of group.modules) {
    writeFileSync(resolve(dataDir, `modules/${module.id}.js`), `export default ${JSON.stringify(module, null, 2)}\n`)
  }
}

const index = moduleGroups.map((group) => ({
  name: group.name,
  modules: group.modules.map(({ id, name, description, apiNames }) => ({ id, name, description, apiNames })),
}))
writeFileSync(
  resolve(dataDir, 'module-index.js'),
  `/**\n * Light module index for the docs shell (sidebar, search, PrevNext, HomePage).\n * Full metadata loads per page from ./modules/{id}.js via catalog.jsx.\n * Keep group names and module order in sync with module-meta.js;\n * validate-registry.mjs fails when the two disagree.\n */\nexport const moduleIndexGroups = ${JSON.stringify(index, null, 2)}\n`,
)

const barrel = [
  `/**`,
  ` * Node-only barrel over the split module metadata. Build scripts and the`,
  ` * Playwright spec import this file; the browser bundle must use`,
  ` * module-index.js (eager shell data) or catalog.jsx's loadModuleRecord`,
  ` * (lazy per-module data) instead.`,
  ` */`,
  ...moduleGroups.flatMap((group) => group.modules.map((module) => `import ${varName(module.id)} from './modules/${module.id}.js'`)),
  ``,
  `export const moduleGroups = [`,
  ...moduleGroups.map(
    (group) =>
      `\t{\n\t\tname: ${JSON.stringify(group.name)},\n\t\tmodules: [${group.modules.map((module) => varName(module.id)).join(', ')}],\n\t},`,
  ),
  `]`,
  ``,
  `export const modules = moduleGroups.flatMap((group) => group.modules)`,
  `export const moduleGuidance = Object.fromEntries(modules.map((module) => [module.id, module.guidance]))`,
  ``,
].join('\n')
writeFileSync(resolve(dataDir, 'module-meta.js'), barrel)

console.log(`Split ${moduleGroups.length} groups into module-index.js + modules/ and rewrote module-meta.js`)
```

```jsx
const metaLoaders = import.meta.glob('../data/modules/*.js')

/** Load a module's metadata, demos, and sources only when its route is opened. */
export async function loadModuleRecord(id) {
  const module = catalog.find((entry) => entry.id === id)
  if (!module) return null
  const metaLoader = metaLoaders[`../data/modules/${id}.js`]
  if (!metaLoader) throw new Error(`Missing metadata for module ${id}`)
  const meta = (await metaLoader()).default
  const files = [...new Set(meta.examples.map((example) => `../demos/${pascalCase(example.demo ?? id)}Demo.jsx`))]
  const loaded = await Promise.all(files.map(async (file) => {
    const demoLoader = demoLoaders[file]
    const sourceLoader = sourceLoaders[file]
    if (!demoLoader || !sourceLoader) throw new Error(`Missing documentation demo for ${file}`)
    const [demoModule, source] = await Promise.all([demoLoader(), sourceLoader()])
    return /** @type {[string, Record<string, any>, string]} */ ([file, demoModule, source])
  }))
  const records = new Map(
    loaded.map(([file, demoModule, source]) => [file, { demoModule, source }]),
  )
  return {
    ...module,
    ...meta,
    examples: meta.examples.map((example, index) => {
      const file = `../demos/${pascalCase(example.demo ?? id)}Demo.jsx`
      const record = records.get(file)
      const demoModule = record.demoModule
      const source = record.source
      const DemoComponent = demoModule[`${pascalCase(example.demo ?? id)}Demo`] ?? demoModule.default
      const Demo = (props) => <DemoComponent {...props} exampleIndex={index} />
      return { ...example, Demo, source }
    }),
  }
}
```
